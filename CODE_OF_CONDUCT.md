# Código de conducta

Este proyecto busca ser un espacio amable y útil para quien está aprendiendo accesibilidad. Al participar en issues, PR y discusiones, te comprometes a:

- Tratar a las demás personas con respeto, también cuando no estés de acuerdo.
- Dar y recibir críticas constructivas: sobre el código y los textos, no sobre las personas.
- Asumir buena fe y explicar sin condescendencia, sobre todo a quien contribuye por primera vez.
- No acosar, discriminar ni publicar información privada de otras personas.

Las conductas inaceptables pueden provocar que se editen o eliminen comentarios, issues o PR, y que se bloquee a quien las cometa.

Para reportar un problema de conducta, escribe a la persona mantenedora por el perfil de GitHub [@AnderCMD](https://github.com/AnderCMD). Las quejas se tratan de forma confidencial.

Este texto se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
